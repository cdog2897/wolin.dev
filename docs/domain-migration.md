## Exact redirect design and ordering

vercel.json uses ordered low-level routes. Do not combine these with top-level redirects/rewrites or a whole-domain Cloudflare/Vercel alias redirect that runs before the exceptions.

1. Continuing noindex header rules first: both admin hosts, /admin, /admin-preview, /sign, /sample, /api and private shell files. Redirect responses for private navigation inherit noindex.
2. GET/HEAD /sign and /sign/* on wolin.dev, www.wolin.dev, www.wolin.studio and both admin hosts → https://wolin.studio with identical path. Apex wolin.studio serves the signing page.
3. GET/HEAD /admin, /admin/ and /admin-preview on public old/new/www hosts → https://admin.wolin.studio/. Query preserved, including preview flags. POSTs are not redirected.
4. GET/HEAD admin.wolin.dev paths → identical path on admin.wolin.studio, except /api, /api/*, /assets/*, private-shell.html and app-shell.html. /sign was handled first. New admin robots and public-looking paths render private protections through duplicated host-specific rules.
5. For wolin.dev, www.wolin.dev and www.wolin.studio, GET/HEAD public redirects normalize /index.html → new /; commercial /index.html aliases → new clean path; retired /90-day-hands-free-local-sensation[/] → new /offers; known Undercover /index.html aliases → new clean path. These precede ordinary host redirects to avoid chains.
6. Same-host-path 308 redirects cover six commercial paths (including optional trailing slash), /calebwolin, /sample, the entire /sample/UndercoverBedandSpas subtree, robots.txt and sitemap.xml. Demo unknown subpaths redirect to new host and receive its scoped noindex 404.
7. Existing clean-path normalization, new/old admin private routes, commercial prerender routing, portfolio shell, private signing/sample shells and demo routing follow. Filesystem remains last; there is no wildcard SPA fallback.

Public-host unknown paths remain 404 locally; static assets remain served on old/public/www hosts, allowing old shells/in-flight pages to load their JS/CSS/images without crossing origins. Every /api path stays local for every method except the explicitly handled admin verification action in application code. No POST/PUT/DELETE/OPTIONS host redirect rules exist. Legacy alias normalization rules are also GET/HEAD-only. 308 preserves methods, but protecting APIs is still essential because crossing hosts would fail same-origin checks.

The declaration evaluator models expected query appending and browser fragment inheritance. Local tests validate exact rules/order/targets, not the managed Vercel query behavior. Live validation must prove UTM parameters, encoded values, repeated keys and fragments are preserved before cutover. Fragments are never sent to the server; redirects omit a fragment so browsers should inherit it. Verify with a browser. Trailing slashes currently retain their requested spelling (same existing content/canonical behavior).
